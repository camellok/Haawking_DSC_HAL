# Platform设计规范

Platform是目标硬件的组合与绑定层。它描述“这个固件使用哪个资源以及如何连接”，HAL描述“该外设能够完成什么操作”。

Platform负责：

- HAL对象的静态存储和外设实例映射；
- 系统时钟和外设时钟源；
- GPIO、pinmux、pad和输入资格；
- 中断注册、优先级、PIE ACK和全局中断启动顺序；
- DMA、XBAR和外部器件控制；
- 固定目标的HAL配置与安全初始化顺序。

Platform不应：

- 机械转发每个HAL运行接口；
- 把协议和产品状态机塞入板级代码；
- 修改HAL对象内部状态；
- 假设reference platform必须被每个项目原样复制。

参考代码必须写明时钟、实例、中断和调用前置条件。实际项目可以采用不同文件结构，只要所有权和依赖方向保持清晰。
